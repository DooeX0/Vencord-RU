# Vencord RU — русский интерфейс Vencord для Discord

Vencord RU добавляет русский язык в интерфейс Vencord для настольного Discord на Windows.

## Возможности

- **Русский интерфейс Vencord.** Переводит разделы настроек, кнопки, уведомления, а также названия, описания и параметры встроенных плагинов.
- **Переключение языка.** Русский и английский можно выбрать в настройках Vencord независимо от языка Discord.
- **Поиск по двум языкам.** Встроенный плагин можно найти по русскому или английскому названию.
- **Обновления из Discord.** Новая версия Vencord собирается с переводом.

## Установка

Для установки нужна Windows 10 или 11 (x64).

1. Полностью закройте Discord. Нажмите правой кнопкой мыши на значок Discord рядом с часами и выберите **Выйти из Discord**.
2. [Скачайте `Vencord-RU-Setup.exe`](https://github.com/DooeX0/Vencord-RU/releases/latest/download/Vencord-RU-Setup.exe) и запустите установщик.
3. Выберите нужный экземпляр Discord и нажмите **Установить**. Если Discord не появился в списке, нажмите **Выбрать папку** и укажите папку, внутри которой находится каталог `app-…`.
4. Запустите Discord. Раздел **Vencord** появится в **Настройках пользователя**.

## Настройки

| Настройка | Где найти | Что делает |
| --- | --- | --- |
| **Язык / Language** | Раздел Vencord в настройках Discord | Выбирает русский или английский интерфейс Vencord. По умолчанию включён русский. |
| **Автоматическое обновление** | Вкладка **Обновления** в разделе Vencord | Позволяет настроить автоматическое обновление сборки. |

## Как пользоваться

1. Откройте **Настройки пользователя** в Discord и найдите раздел **Vencord**.
2. Откройте **Язык / Language** и выберите **Русский** или **English**.
3. Нажмите **Применить / Apply**. Discord перезагрузит интерфейс и сохранит выбранный язык.

Чтобы найти встроенный плагин, откройте **Настройки пользователя → Vencord → Плагины**. В поиске можно вводить русское или английское название.

## Как обновить

1. Откройте **Настройки пользователя** и найдите вкладку **Обновления** в разделе Vencord, под **Помощником по патчам**.
2. Нажмите **Проверить наличие обновлений**. Если есть новая версия, нажмите **Обновить сейчас**.
3. Дождитесь окончания сборки и перезапустите Discord.

Для обновления нужен интернет. В первый раз сборка может занять больше времени, поскольку скачиваются зависимости.

## Если что-то пошло не так

- **Раздел Vencord не появился.** Полностью закройте Discord через значок рядом с часами, повторите установку и проверьте, что выбрали тот экземпляр Discord, который запускаете.
- **Установщик сообщил об ошибке.** Откройте журнал `%APPDATA%\Vencord\install.log`. Этот путь можно вставить в адресную строку Проводника.
- **Нужно вернуться к официальному Vencord.** Закройте Discord и установите обычную сборку через [официальный установщик Vencord](https://vencord.dev/download/).

## Как это работает

1. Скрипт сборки получает исходники Vencord и подключает словарь перевода.
2. После проверки и компиляции Discord загружает сборку с русским интерфейсом.
3. При обновлении скрипт повторяет этот процесс. Если сборка завершится ошибкой, Discord продолжит использовать предыдущую рабочую версию.
